# Lab 5 - Viva Answers

1. **What is an array?** A collection of elements of the same data type stored in contiguous memory locations.
2. **1D vs 2D array?** A 1D array is a single row of elements (`int a[5]`); a 2D array is a table of rows and columns (`int m[2][3]`).
3. **What is array indexing?** Accessing an element by its position number. Indexing starts at 0, so `arr[0]` is the first element.
4. **What is array traversal?** Visiting every element of the array once, usually with a loop.
5. **What is Bubble Sort?** A sorting algorithm that repeatedly swaps adjacent elements if they are in the wrong order, pushing the largest element to the end in each pass.
6. **Why use arrays?** To store many values of the same type under one name and process them easily with loops, instead of declaring many separate variables.
7. **Time complexity of Bubble Sort?** O(n^2) in the worst and average case; O(n) best case if already sorted with an early-exit flag.
8. **Array vs variable?** A variable holds one value; an array holds multiple values of the same type accessed by index.
9. **Declare a 2D array in C++?** `int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};`
10. **Why are loops important with arrays?** They let us visit, search, and modify every element without writing repeated code; nested loops are needed for 2D arrays.
